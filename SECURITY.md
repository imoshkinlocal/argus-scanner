# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выходят для последней minor-версии (`1.1.x`).

| версия | поддержка |
|---|---|
| 1.1.x | да |
| < 1.1 | нет |

## Как сообщить об уязвимости

Не открывайте публичный issue. Используйте приватный канал GitHub:

1. вкладка **Security** → **Advisories** → **Report a vulnerability**;
2. либо напишите мейнтейнеру через GitHub (`@imoshkinlocal`).

Пожалуйста, приложите:

- версию (`argus version`) и способ установки (архив / `.deb` / из исходников);
- минимальный воспроизводимый пример (файл или проект);
- ожидаемое и фактическое поведение.

Ответ в течение 7 дней, исправление — по возможности в ближайшем релизе.
Мы не применяем embargo дольше 90 дней без согласования.

## Проверка артефактов

К каждому релизу приложен `SHA256SUMS`:

```bash
sha256sum -c SHA256SUMS
```

Сборка воспроизводима workflow `.github/workflows/release.yml`, который
использует только опубликованные версии зависимостей и автоматический
`GITHUB_TOKEN`.

## Область действия

- сам сканер и его CLI;
- правила SAST в `argus/sast/rules/`;
- упаковка: `debian/`, `packaging/`, портативный архив.

Вне области: уязвимости в сторонних зависимостях (Semgrep, tree-sitter,
Python-пакеты) — о них сообщайте их мейнтейнерам; мы обновим версию в
следующем релизе.
